## v1.23.0-custom.3 (2026-09-15)

基于上游 chatbox v1.23.0 (61191ae7) 的自定义版本。

### 本版新增

- **CUSTOM-20260907-001**: 键盘快捷键「显示/隐藏应用窗口」新增 `Shift+Alt+C` 预设组合
  - 在原有的 `Alt+\`` / `Ctrl+Space` 之外增加第三个可选组合，避免与其他应用的全局快捷键冲突
  - 可在 设置 → 键盘快捷键 → 显示/隐藏应用窗口 的下拉框中直接选择（该选项同时参与配置校验，旧配置不受影响）

### 修复与改进

- **文档**: 坑点库（`CUSTOMIZATIONS/docs/pitfalls.md`）新增「仓库目录改名/移动后 pnpm workspace 软链指向旧路径」条目（现象 → 根因 → 解法 → 验证），避免后续换目录后重复排查 `resolve import @chatbox/core` 失败
- **协作规范**: AI 协作文档（AGENTS.md 与 `.agents/skills/*`）补充执行约束说明

### 已知问题

- 安装包未做代码签名（上游签名脚本已随 open edition 移除），Windows SmartScreen 可能提示未知发布者
- Windows 下 `pnpm run test` 有约 16~31 个上游用例失败（`src/main/skills/*` 路径分隔符/symlink、`sandbox/*`、`session-attachment-rag/*` 等环境敏感用例，不同运行间数量浮动）。上游既有问题，与本次改动无关（本版本代码改动仅为快捷键枚举数组追加一项，无测试引用该符号）；`pnpm run lint` 的 9 个 error 同样位于未改动的上游文件
