## v1.23.0-custom.2 (2026-09-03)

基于上游 chatbox v1.23.0 (61191ae7) 的自定义版本。

### 本版新增

- **CUSTOM-20260903-008**: 新增 `Ctrl+H`（macOS 为 `⌘+H`）快捷键直接打开会话「历史话题」面板
  - 此前只能通过右上角 `…` 菜单进入；快捷键可在 设置 → 键盘快捷键 中查看
  - 与菜单入口遵循相同的可用性规则（Work 模式且无归档话题的会话不响应）
- **快捷键可靠性（CUSTOM-20260903-004）**: 全局快捷键注册失败不再静默——失败时弹出提示（含被占用的组合键），并在窗口重新获得焦点时自动重试
- **命名开关（CUSTOM-20260903-002）**: 新增「使用搭档的新话题开启自动命名」开关（设置 → 对话设置 → 功能，默认关闭）；开启后搭档会话首轮对话用话题命名模型同时生成会话名与话题名
- **稳定性（CUSTOM-20260903-005/006）**: 修复修改设置后可能出现 `getSettings is not a function` 崩溃、以及搭档会话发消息偶发无回复的问题（设置读取全链路加固）

### 修复与改进

- **CUSTOM-20260903-009**: 修复本地打包脚本在杀毒软件（如火绒）实时扫描新 exe 时偶发的 `rcedit: Unable to commit changes` 失败（打包脚本加入自动重试）
- **CUSTOM-20260903-003**: 新增本地操作与打包脚本套件（`CUSTOMIZATIONS/scripts/manager.sh`：install/dev/build/lint/test/unpacked/setup/artifacts/clean）
- **CUSTOM-20260903-007**: 仓库文档体系重组（registry 账本按文件聚合、代码地图 architecture.md、坑点库 pitfalls.md）
